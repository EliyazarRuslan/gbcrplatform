Executive Summary

Goldbell Car Rental achieved exceptional cost savings by building the GBCR Fleet Management Platform entirely in-house, leveraging AI-assisted development tooling (Claude Code Pro) instead of engaging an external software vendor. An external provider quoted SGD 50,000 for initial implementation plus SGD 1,000 per month in ongoing support — totalling SGD 86,000 over three years. The in-house approach delivered the same scope of work for approximately SGD 3,240 per year (the cost of the AI development tool alone), representing savings of 95% in Year 1 and 89% over three years. Beyond pure cost reduction, this approach ensures full intellectual property ownership, zero vendor lock-in, and complete alignment with Goldbell's operational workflows — a strategic capability that can be replicated across future digital transformation initiatives.

2

Project Overview — What Was Built

Fleet Management Platform Full-stack web application built with Next.js, React, and TypeScript. Production-grade architecture with server-side rendering and optimised performance.
Real-Time Vehicle Tracking & Booking Live fleet status, availability calendars, booking workflows, and vehicle assignment — replacing manual spreadsheet-based processes.
Microsoft SSO & Azure AD Integration Single sign-on via Azure Active Directory. Role-based access control for internal staff with no additional identity infrastructure required.
Enterprise System Integrations Bidirectional data sync with Microsoft Dynamics AX (ERP), IBM Maximo (asset management), and Microsoft Fabric (analytics platform).
Customer Management & Inspection Workflows Customer CRM, digital vehicle inspection checklists, condition reporting, defect tracking, and maintenance scheduling.
AI-Powered Analytics & PWA Embedded analytics dashboards, AI-driven fleet insights, and a Progressive Web App shell for mobile-responsive access on any device.

Risk Mitigation

Source code fully owned and version-controlled. The complete codebase is managed in a Git repository under Goldbell's control, with full commit history, branching strategy, and code review workflows in place.

Built on mainstream, widely-supported technology. Next.js, React, TypeScript, and Microsoft SQL Server are industry-standard technologies with large talent pools and long-term vendor support — not proprietary stacks.

Any competent developer can maintain the codebase. The platform is not dependent on a single individual. Standard patterns, documented APIs, and modern tooling ensure any qualified developer can contribute or take ownership.

Documentation and architecture are well-structured. Technical documentation, data models, API specifications, and deployment guides are maintained alongside the codebase to ensure continuity.

7

Recommendation

Based on the demonstrated cost savings of 89–95%, full IP ownership, rapid delivery, and strategic alignment with Goldbell's operational needs, the IT Department strongly recommends continuing the in-house, AI-assisted development approach for all future digital projects where scope and complexity are well-understood. This model — leveraging existing infrastructure, existing staff, and AI development tooling — has proven to deliver enterprise-grade software at a fraction of vendor cost while retaining control, flexibility, and institutional knowledge within the organisation. Where external expertise is genuinely required, it should be engaged selectively for narrow, defined deliverables rather than broad platform ownership.
