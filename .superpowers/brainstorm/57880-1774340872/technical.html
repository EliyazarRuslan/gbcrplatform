Technical Design Details

Offline sync, push notifications, and key libraries

Offline Inspection Sync Flow
1
Inspector fills out form
Photos, damage marks, signatures, readings — all captured natively
2
Saved to local SQLite
Inspection data + photos stored locally with status: pending_sync
3
Network available?
NetInfo API detects connectivity. If online → sync immediately. If offline → queue for later.
4
Background sync
expo-task-manager runs sync when connectivity returns. Uploads inspection data, then photos. Retries on failure.
5
Status updated
Local record marked synced. Inspector sees green checkmark in the offline queue screen.

New API Endpoints Needed

  • POST /api/push/register — Register device push token
  • DELETE /api/push/unregister — Remove push token on logout
  • POST /api/inspections/sync — Batch upload offline inspections
  • POST /api/inspections/photos/upload — Multipart photo upload (mobile-optimized)
